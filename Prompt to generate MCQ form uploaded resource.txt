CIVIZ WEBSITE JSON SCHEMA

Generate JSON compatible with the existing CIVIZ Quiz Website.

Use this structure:

{
  "title": "Topic Title",
  "description": "Short description of the quiz",
  "questions": [
    {
      "id": "q1",
      "question": "Question text",
      "options": [
        "Option A",
        "Option B",
        "Option C",
        "Option D"
      ],
      "answerIndex": 0,
      "explanation": "Explanation of the correct answer",
      "difficulty": "Easy",
      "marks": 1,
      "negativeMarks": 0
    }
  ]
}

FIELD REQUIREMENTS

- title: Required. A clear title for the quiz.
- description: Required. A concise description of the material covered.
- questions: Required. An array containing every generated question.
- id: Required. A unique identifier for each question, such as q1, q2, q3, and so on.
- question: Required. The complete question text.
- options: Required. Exactly four answer-option strings.
- answerIndex: Required. A zero-based integer identifying the correct option: 0 for the first option, 1 for the second, 2 for the third, and 3 for the fourth.
- explanation: Required. A concise, accurate explanation.
- difficulty: Use "Easy", "Medium", or "Hard".
- marks: Use 1 unless the question reasonably warrants a different score.
- negativeMarks: Use 0 unless negative marking is deliberately appropriate.

OPTIONAL FIELDS SUPPORTED BY THE WEBSITE

Use these only when relevant:

- questionMath: A LaTeX expression displayed with the question.
- explanationMath: A LaTeX expression displayed with the explanation.
- image: A valid relative path to an existing image file.
- imageAlt: Accessible alternative text describing that image.

Do not add unsupported properties such as topicId, conceptId, tags, answers, correctAnswer, or options[].isCorrect unless the website's code has explicitly been updated to support them.

For ordinary questions, put mathematical notation directly in the question or explanation string when possible. Use questionMath and explanationMath only when a separate displayed equation is useful.
